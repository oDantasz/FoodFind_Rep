    Política de Privacidade

    Versão 4.0 · Projeto acadêmico da FATEC Ipiranga (ADS) · Lei nº 13.709/2018 (LGPD)

    1. Quem somos

    O FoodFind é um projeto acadêmico desenvolvido por Pedro Augusto Dantas Aranda e Vinicius Tofani Siqueira para a disciplina de Laboratório de Engenharia de Software. O controlador dos dados é a equipe responsável pela instalação do sistema.

    2. Dados que coletamos

    • Conta: nome, e-mail, tipo de conta e senha (guardada apenas como hash scrypt; ninguém consegue lê-la).
    • Sessão: um cookie ff_session estritamente necessário para manter você conectado. O banco guarda só o hash desse token.
    • Avaliações: nota, comentário e data. O nome aparece abreviado (ex.: "Pedro A.").
    • Benefícios: campanhas resgatadas, número do voucher e data de uso.
    • Restaurantes (donos): dados do estabelecimento, fotos e campanhas.
    • Último acesso: data e hora do último uso com a conta conectada (atualizada no máximo a cada 30 minutos).
    • Visitas: contamos quantas vezes o site foi aberto em cada dia, apenas o número total. Não guardamos IP, não usamos cookie para isso e não identificamos quem visitou.

    Quem vê esses dados: o administrador do FoodFind vê nome, e-mail, tipo de conta, data de cadastro, último acesso e a quantidade de restaurantes, avaliações e benefícios de cada conta, para administrar o sistema (por exemplo, redefinir senhas e aprovar restaurantes). Esses dados não são vendidos nem compartilhados.

    3. Localização

    A localização só é usada depois que você aceita o aviso e o navegador pede permissão. Ela serve apenas para buscar restaurantes próximos, é enviada ao servidor só no momento da busca e não é armazenada. Se preferir, pesquise por endereço ou bairro.

    4. Serviços de terceiros

    Para mostrar o mapa e os restaurantes públicos, o FoodFind consulta o OpenStreetMap (Overpass e Nominatim) e servidores de mapa (OpenStreetMap e Esri). As bibliotecas de mapa e de leitura de QR Code são carregadas do unpkg.com com verificação de integridade (SRI). Quando publicado na internet, o FoodFind roda num serviço de hospedagem (por exemplo, Render) e pode guardar uma cópia do banco de dados e das fotos num banco PostgreSQL gerenciado (por exemplo, Neon), para que os dados não se percam quando o servidor reinicia.

    5. Seus direitos

    Em Minha conta você pode corrigir seu nome, trocar a senha, sair de todos os dispositivos, exportar seus dados em JSON e excluir sua conta com todos os dados vinculados.

    6. Retenção e segurança

    Os dados ficam enquanto a conta existir. Sessões expiram em 30 dias e são removidas automaticamente. Usamos HTTPS quando disponível, cookies HttpOnly/SameSite, limite de tentativas de login e cabeçalhos de segurança.

    7. Contato

    Dúvidas sobre privacidade: fale com a equipe do projeto pelo repositório do FoodFind.

    Termos de Uso

    Versão 4.0 · Projeto acadêmico

    1. O serviço

    O FoodFind ajuda a encontrar restaurantes, consultar informações e resgatar descontos oferecidos pelos próprios estabelecimentos. O FoodFind não processa pedidos nem pagamentos.

    2. Contas

    Você é responsável pela sua senha. Contas do tipo Cliente avaliam e resgatam benefícios; contas do tipo Restaurante cadastram estabelecimentos e campanhas.

    3. Avaliações

    As avaliações devem refletir experiências reais. Não publique dados pessoais, ofensas ou propaganda.

    4. Campanhas e vouchers

    O restaurante define as regras de cada campanha. Cada cliente pode resgatar uma vez por campanha. O voucher vale até o fim da campanha e só pode ser usado uma vez.

    5. Restaurantes do OpenStreetMap

    Para assumir um estabelecimento que já aparece no mapa, o responsável envia um pedido, que é analisado por um administrador.

    6. Limitações

    Dados públicos do OpenStreetMap podem estar incompletos ou desatualizados. Este é um projeto acadêmico, oferecido sem garantias.
